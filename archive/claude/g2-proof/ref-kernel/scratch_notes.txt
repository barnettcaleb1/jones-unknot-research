1. Half-twist vs separating twist (main objection).
   T_{c0} = (s1 s2)^3 lifts to h_c in M_2 with h_c^2 = T_gamma (= psi_0 = (s1 s2)^6), and h_c acts on H as J_c (-1 on P, +1 on P^perp).
   kappa_f = [h_c, f] has Mess class (J_c - 1)[f] and tau_2(kappa_f) = (J_c - 1) tau_2(f): neither is 0 in general.
   Exact: ord_{A=zeta}(rho - I) for f = T_d^2, d = s3(c0):  [(s1 s2)^3, f] -> 1,  [(s1 s2)^6, f] -> 2.
   So kappa_f (stated form) is in F_1 \ F_2, hence not in [I_2, I_2] (phi^(1) is abelian on I_2) and not in F_2.
   Lattice independence: TL and Kasahara lattices both have irreducible reduction at q = -1, so they are homothetic over the
   local ring and ord is lattice-independent; commutators have exponent sum 0, so the bracket scalar cancels.
   Correct first-order condition for ANY candidate f (rho(f) fixes [v_0]): [Delta_1(f), P_{u0}] = 0, i.e. m(f) in Q u_0.
   For the half-twist form this is "kappa_f in F_2"; for [(s1 s2)^6, f] it is "in F_3". The pair of lines passes only order 0 for free.

   w := (2D_20 - 1)u_1 - (2D_10 - 1)u_2 satisfies <w, u_0> = (2D_20-1)(4D_10-2) - (2D_10-1)(4D_20-2) = 0 identically.
