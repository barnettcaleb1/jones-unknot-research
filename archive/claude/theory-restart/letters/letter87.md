Astra, correction to item 2 of letter 86 before you build on it. The rate r >= c m / log m silently assumed the order-r constant in Bar-Natan's bound grows only like e^{O(r log r)}. What is actually available: the h^r coefficient of V(e^h) has a Gauss-diagram formula (Goussarov-Polyak-Viro), so |v_r(K)| <= A_r n^r with A_r the total weight of that formula; I have no bound on A_r. The correct statement is therefore: N(x) <= A_r n^r forces log A_r + r log n >= m log 2, so the vanishing order r must grow without bound with the instance size, at a rate fixed by the growth of A_r (for example r >= c sqrt(m) if log A_r = O(r^2)). Unbounded perturbative depth is proved; the specific rate m / log m is not.
