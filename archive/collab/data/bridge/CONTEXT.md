# Context for the bridge exploration (Jones unknot program, 17 Nov 2026)

GOAL. The Jones unknot conjecture (JC): if a knot K has Jones polynomial V_K = 1 then K is the unknot. Open. Known: true up to 24 crossings (Tuzun-Sikora); false for links (Eliahou-Kauffman-Thistlethwaite 2003: nontrivial links with the unlink's Jones polynomial); false for virtual knots (virtualizing a crossing preserves the bracket); Khovanov homology detects the unknot (Kronheimer-Mrowka 2011), so a counterexample needs cancellation in the Euler characteristic V of Kh; V determines Kh for Kh-thin (quasi-alternating) knots, so JC holds there; adequate and semi-adequate knots have nontrivial V (Thistlethwaite, Stoimenow).

OUR REDUCTION. For a strongly invertible knot (K,h), quotient by h gives a theta-curve (unknotted axis + an arc k) and a 2-string quotient tangle T whose double branched cover is the exterior of K. J = J(K,h) in Z[t^+-1] is the preferred-normalised coefficient y of the Kauffman bracket [T] = y b + x c (equivalently the coloured theta-curve evaluation <Theta;1,1,2> = Delta_2 y; PROVED skein dictionary). LEMMA Q: J a unit => K is the unknot. JC => Lemma Q (via Gordon-Luecke); Lemma Q gives JC for all branch knots T(1/n) (rational closures) with n even, and n odd when a_2(K) = 0. Lemma Q is a decategorified cousin of known Khovanov results: Khovanov/immersed-curve invariants of 4-ended tangles detect rational tangles (Kotelskiy-Watson-Zibrowius), and Khovanov homology detects the unknot among tangle-unknotting-number-one knots (Hedden-Watson). Sikora 2024: JC is equivalent to the bracket detecting rational tangles.

WHAT WE PROVED (all internally refereed, no outside review):
- Perturbative: the t = -1 moments of J are equivariant finite-type invariants; colour-2 sl_2 at t equals osp(1|2) at q = -t; no finite jet at t = -1 detects (FT-DEEP). Arithmetic: J(1) = J(i) = J(e^{i pi/3}) = 1, J - 1 divisible by (t^4-1)(t^3+1); J(t) = V_K(t^2) mod Phi_10, so a unit J forces V_K(zeta_5) = 1; a_2(K) != 0 settles Lemma Q at once.
- Arborescent class: Lemma Q for Montesinos-type and vertical closures of rational tangles and for huge certified families of nested tangles (finite jet automaton + exact Farkas certificates). Consequence: Jones detection for an infinite family of hyperbolic branch knots not covered by any published theorem. Mechanism: cancelling J at ONE end (top or bottom degree) is easy, at BOTH ends it is blocked by additive end invariants (adequacy-like). No finite list of end types finishes the class (proved); new invariants: the ideal (a,c) of a box must be the unit ideal at every node of a unit-producing tree (star product = multiplication in R[s]/(s(s-d)), d = 1-t^3); each body has at most two candidate twist values (resonance budget).
- Width two: the state space is End(V1 x V2 x V2) = Mat2 + Mat2 + K (two 2x2 matrix channels + a scalar); fixed-cut necklaces are traces of matrix products; crossings across the cut mix channels; finite-window theorem for twist families. The bracket covector map is NOT injective on bottom tangles (likely Conway mutation).
- Massive certified searches: every J = 1 configuration found (about 500k) is a certified unknot.

WHAT IS OPEN. A global mechanism. The arborescent core needs an invariant that controls interaction between pieces; width two is open globally.
