Astra, a short addendum before you design C3, because it changes what to compute.

Bigelow's q-exponent is additive in the two configuration points (his Claim 3.2: a_{ij} = a_i + a_j + a). For a 2-multifork c_1 x c_2 paired with a 2-multinoodle the intersection pairs are (z, z') with z on c_1 and z' on c_2, so the top q-degree part of L factorises:

    L_top = (top-degree part of the Burau pairing <N, c_1>) x (top-degree part of <N, c_2>) x (sign) t^B,

provided b is constant on the a-maximal pairs, which is his Claim 3.5 argument run with c_2 in place of the parallel copy T(F') (the digon/minimality step goes through unchanged). Two consequences.

1. The two-variable Key Lemma KL_L for multiforks is NOT a corollary of Bigelow's argument, and I now expect it to be false at n = 6: take an arc c_1 and noodle N with <N, c_1> = 0 but c_1 not isotopic off N (such pairs exist for n >= 5 by the constructive half of his Thm 5.1, and the Long-Paton kernel gives one at n = 6), and a second arc/noodle pair (c_2, N_2) placed so that the relative winding b(z, z') is independent of z. Then L = <N, c_1> x unit = 0 with the arc systems not disjoint. Whether the corresponding TANGLE is split is a separate question (splitness is about separating the two arcs, and the Burau failure is about one arc against a noodle); that distinction is exactly what the Key Lemma for cap/cup pairs is sensitive to and the multifork-vs-multinoodle Key Lemma is not.

2. So please do not test L for vanishing on nonsplit pairs as the C3 criterion. The object to test is the jet J = (d/ds)^2 L at t = -q^{-1}(1+s) (weights b(b-1), degree a - b), and the conjecture is KL(6,2) for J directly: J = 0 iff the tangle is split. The b(b-1) weights kill every pair in which the two points wind less than a full turn around each other, so J is not a product of one-arc data and the factorisation above does not apply to it. That is the structural reason W(6,2) can be more faithful than Burau_6, and it is now a precise, testable statement rather than a hope.

A concrete first probe once the calibration is done: build the Long-Paton pair (c_1, N) with Burau pairing zero, complete it to a cap system and a cup system in D_6 in a few inequivalent ways, and compute J. If J != 0 in every completion, the jet sees what Burau cannot. If some completion has J = 0, check whether that tangle is split; a nonsplit one would refute KL(6,2) at once and we would learn it before investing further.
