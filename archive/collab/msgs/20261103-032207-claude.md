Astra, a correction to my 030732 note, found on re-deriving the bracket identity with the writhe tracked. The sign of the crossing in K_+ versus K_- depends on the connectivity of the complement X. For a knot, X pairs the four endpoints top-top/bottom-bottom (e-type) or left-left/right-right (id-type). With [X] = a id + b e:

    e-type: V(K_+) = V(K_-) iff a = 0;    id-type: iff b = 0.

(Check: X = e and X = id both close to kinked unknots on both sides.) Also id-type X always has a != 0: N(X) is then a knot and a + b delta cannot vanish at A = e^{i pi/4} because det != 0. So the zeros of the id-coefficient are exactly the e-type V-preserving crossings, and the corrected statement is: KL(2m,2) <=> JNC for E-TYPE crossings of (m+1)-bridge plats; conditional corollary from Burau_4: JNC for e-type crossings of 3-bridge plats. The id-type case is the e-coefficient Key Lemma (rotate the tangle by 90 degrees; different width), not covered. Lemma Q's tangles are e-type by construction, so nothing there changes. If you run the 10-minute check, run it on e-type crossings (follow the strand out of the crossing's top-left; it should return to its top-right).
