## 1. Exact formula, including the corrections

Let x lie on source arc c0 and target loop gamma_m, and y lie on c1 and gamma_(1-m). For each nonempty matching choose an actual reference intersection (x_m,y_m). Trace its configuration path from the global base and compute its exponents a_m,b_m independently.

Define CLOSED paths

    L_x = gamma_m[x_m -> x] followed by c0[x -> x_m],
    L_y = gamma_(1-m)[y_m -> y] followed by c1[y -> y_m].

Then

    a(x,y) = a_m + sum_p wind_p(L_x) + sum_p wind_p(L_y),
    b(x,y) = b_m + 2 wind_(x_m)(L_y) + 2 wind_y(L_x).

The sum over p is over the six real punctures. These identities follow by moving one labeled point at a time; the source and target rectangles supply the order-changing homotopies.

If p_m = m XOR m_base, put

    w0_m(y) = (b_m-p_m)/2 + wind_(x_m)(L_y).

Your requested identity is precisely

    b(x,y)-p_m = 2 [w0_m(y)+wind_y(L_x)].

The constant is matching- and lift-dependent. An unspecified open source path does not have the required invariant integer winding. In the checks, all windings and reference constants were obtained from actual paths; w0 was not defined as a residual from the measured b.

For the colored sum, write A_x=sum_p wind_p(L_x), W_x=wind_y(L_x), and let eta_x be the local crossing sign at x divided by that at x_m. If a0,b0,epsilon0 are the exponents and raw sign of the independently traced anchor (x_m,y), then

    Phi_geom(q,-q^-1)
      = sum_(m,y) epsilon0 (-1)^b0 q^(a0-b0)
                    sum_x eta_x q^(A_x-2W_x).

Before specialization the inner weight is q^A_x (t^2)^W_x. Thus the extra puncture has weight t^2, becoming q^-2.

Two bookkeeping points matter:

- The forgetful fibration is on **ordered** configurations. Passing from unordered pairs requires the labeled double cover/matching bookkeeping. This is the standard [Fadell–Neuwirth configuration-space fibration](https://journals.msp.org/mscand/article/view/2674); the half-exchange convention is [Bigelow §2](https://web.math.ucsb.edu/~bigelow/publications/08.pdf).
- In our orientation convention, the raw matching permutation sign (-1)^m cancels the exchange-parity sign (-1)^b on the TL line. There is no additional naked (-1)^m if the inner one-point pairings already use ordinary local crossing signs. It can appear only with compensating signed units. The explicit anchor prefactor above avoids that ambiguity.

This is a colored rank-one-local-system intersection pairing in a seven-punctured disk; it need not be treated as an ordinary equal-weight Burau matrix entry.
