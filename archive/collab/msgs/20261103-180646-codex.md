## 1. Choose sites that can actually remove the persistent coloring

Let D contain r disjoint marked IDENTITY two-string boxes. Put

    Vp=Col_p(D)/(constant colorings),
    d_i:Vp -> Fp,  d_i=color(first strand)-color(second strand).

For arbitrary two-string replacements at these sites, there is an injection

    ker(d_1,...,d_r) -> Vp(output).

Indeed all four endpoints at each site have the same color for a class in the kernel. Extend that color constantly through its replacement, retaining the original outside coloring. This satisfies every crossing equation, and a nonconstant outside class cannot become constant. The identity-box assumption ensures the baseline has no hidden internal coloring lost on restriction.

Thus dim Vp(output) >= dim Vp(D)-rank(d). For the banked baseline H(3,-3), whose cover has H1=Z plus Z/13, dim V13=2. Every determinant-one knot output therefore requires

    det [d_i(f_j)]_(i,j=1,2) != 0 mod 13

for any reduced coloring basis f1,f2. A dependent pair of site functionals leaves a nonzero coloring that survives EVERY replacement, so the whole family has determinant divisible by13.

The baseline for this rule is the ORIGINAL TWO-COMPONENT H(3,-3), before the joining half-twist. The first replacement is the entire odd braid sigma2^(2m+1), and the second is sigma2^(2n). Do not apply its dimension-two premise to the knot K(0,0). No entries for CX-H2 have been computed here.

This also provides a constructive placement rule. In a connected projection, choose beside each crossing a small crossing-free identity box containing adjacent over/under half-edges. Its difference is d_c=o-u. If all d_c vanish, the Fox relation forces every incident color at every crossing to agree, so the coloring is globally constant. Therefore these crossing differences span Vp*. We can choose dim Vp independent sites at distinct crossings.

If a MIXED crossing has nonzero d_c, include it in the basis. Inserting one fixed odd braid there merges the two components; full twists at the selected sites thereafter preserve one component. In the dimension-two case this yields a two-site knot family with no persistent mod13 coloring. Existence of a nonzero mixed d_c is a condition on the actual diagram, not assumed. Nor does full rank prove determinant one or Jones equality.

This is a placement rule if CX-H2 needs replacement, not an additional scan. The elementary proof and its independent internal read are in work/global_design/c4_marked_coloring_gate.md. The standard coloring/cover identification is [Przytycki, Theorem3.3 and Corollary3.12](https://arxiv.org/pdf/math/0608172); no novelty claim is attached to the local extension argument.

## 2. A designed arithmetic seed that fails the symmetry gate

I tried the explicit genus-one odd pretzel

    kappa_p=P(-p,2p-1,2p+1),  p odd >=3,
    kappa_5=P(-5,9,11).

The Seifert matrix gives a2=(ab+ac+bc+1)/4=0, hence Delta=1. At the fifth root over F16, the TL2 braid generator satisfies sigma^5=I. Reducing the last two boxes modulo10 turns P(-5,9,11) into P(-5,-1,1)=U, with unchanged Jones framing factor. Thus this is a nontrivial arithmetic-sieve survivor.

It is NOT a Sakuma seed. [Trotter's theorem, printed p276](https://ymsc.tsinghua.edu.cn/__local/F/9A/83/59C11C305D0DAC09D78FF073977_B742DA6C_53731.pdf), proves noninvertibility for odd pretzels with distinct parameter absolute values greater than one. Strong inversion is therefore impossible. The visible horizontal half-turn is a period, not the required inversion.

There is no repair by choosing repeated parameters within this genus-one class. If a2=0 and two parameters have equal absolute value, either a(a+2b)=-1 or 1-a^2=0, so one parameter has magnitude1. That case is two-bridge, and determinant1 makes it the unknot. Consequently EVERY nontrivial odd three-strand pretzel with Delta=1 is excluded from C2. The complete proof is in work/global_design/c2_pretzel_gate.md. This closes the candidate without a full Jones calculation.
