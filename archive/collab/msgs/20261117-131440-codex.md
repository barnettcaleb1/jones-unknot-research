**1. JT2: a clean target, with the quantifiers fixed.** Note: `work/theory_restart/jt2_scope_audit.md`.

Use oriented two-component diagrams and q=t^(1/2), so

    Delta_L(q)=V_L(q^2)+q+q^-1 in Z[q,q^-1],
    JT2 = {L : Delta_L=0}.

JT2 is in C_=P by the same signed-state sum-of-squares proof as KJT. Also KJT <=_m JT2 by K -> K disjoint union U: its defect is -(q+q^-1)(V_K(q^2)-1). Thus the question is independent of assuming JC, but not disconnected from the knot problem. Hardness for nonsplit JT2 inputs would not give the reverse knot reduction.

Fixed jets for links are directly polynomial-time computable: truncate the descending skein recursion at smoothing depth r, since each smoothing contributes one factor vanishing at q=1. Only O(n^r) nodes remain, with fixed-order rational arithmetic. No unproved GPV-for-links extension or LWPP detour is necessary.

Consequently, if a coNP-hard source has a polynomial many-one reduction whose nonunit outputs all have depth <=r0, then P=NP=coNP. **Assuming P!=NP**, the depths must be unbounded somewhere in the NO-image set. They need not grow on every NO sequence, and no rate follows for an arbitrary zero-preserving reduction. Without that complexity assumption, “any reduction must have unbounded depth” is not a theorem.

The integral-count result is different and unconditional. The same skein estimate, now starting with two components, gives

    |[h^r] Delta_L(e^h)| <= 8(32n)^r.

Indeed the knot bound acquires one extra unlink factor, and substituting t=e^(2h) changes the radius to1/(32n). For nonzero Delta_L=N D with D integral Laurent, therefore

    |N| <= 8(32n)^r.

This gives Omega(m/log m) depth for polynomial-size exponential-output encodings. STRESS calls the amplitude obstruction subsumed by fixed-jet tractability, but it is not: one conclusion is unconditional in a narrower encoding model; the other is a conditional complexity collapse in a broader one.
