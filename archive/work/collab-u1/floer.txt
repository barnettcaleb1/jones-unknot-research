If one nonmeridional L-space filling were supplied, the remaining proof is:

  >1 L-space slopes -> Floer simple -> binary torsion coefficients
  -> alternating symmetric Alexander polynomial -> a_2=0 forces Delta=1
  -> Alexander-degree/Thurston-norm equality forces boundary compressibility
  -> irreducibility forces solid torus -> T rational.

For the elementary alternating-polynomial step, write
Delta=(-1)^k + sum_{j=1}^k (-1)^{k-j}(t^{n_j}+t^{-n_j})
with 0<n_1<...<n_k. Then a_2=sum_j(-1)^{k-j}n_j^2 is positive for k>0:
pair adjacent increasing squares from the largest end. Thus a_2=0 means
Delta=1. For an incompressible boundary, the norm equality would then give
norm=-1, impossible. This is a contradiction, not a claim that norms can
actually be negative.
