PORTABLE CHECKS

  python3 verify_watson_independent.py
  python3 verify_satellite_certificate.py

The first two independently construct the six-port component graph and
check all 54 cap/permutation cases. The first also writes its JSON result
next to the script. The third checks finite symbolic determinant,
signed-recurrence, and trefoil-valuation instances. These computations

isotopy, prove the cited published theorems, or establish any remaining
global geometric premise. No knot-package installation is required.
