WHY THESE RECORDS ARE UNAFFECTED

1. Independently reconstruct the 12-vertex incidence graph from each saved
   braid word and its cap/cup state indices. A positive or negative braid
   generator swaps the same two endpoint labels; add the cap edges above
   and cup edges below. In all 288 cases this gives exactly two proper arcs,
   no closed components, and endpoint pairing (01)(23). This independently
   agrees with the archived geometry fields.

2. For this two-arc connectivity, the numerator matching (01)(23) gives
   exactly TWO actual link components. The denominator matching (02)(13)
   gives exactly ONE actual link component. These are elementary incidence
   counts; no knot recognition is involved.

3. Count components represented by each saved PD directly: create one
   vertex for every arc label and join opposite entries (row[0],row[2])
   and (row[1],row[3]) at each crossing. Count the resulting connected
   components. In all 288 numerator PDs this is two; in all 288 denominator
   PDs this is one. No saved PD is empty. These counts also agree with the
   saved pre-simplification component counts.

Consequently the PD already contains every actual closure component in
all 576 relevant closures. The fixed helper would add zero crossing-free
components. The omitted-component bug cannot change these diagrams or
their saved recognition conclusions.
