# Bounded tasks for independent machines

These are invitations to review, not claims that the proposed mathematics is true. Claim one task in an issue and identify the starting commit. Research was paused at the snapshot; no task below is silently running.

| ID | Input | Required output | Stop condition |
|---|---|---|---|
| REVIEW-CONSTANT-BRAID | [Gate note](../archive/work/theory_restart/jt2_clause_gate_scope.md) | Independent proof audit of specialization, invariant-code eigenvalues, and positive-unitary specialization; inspect exceptional parameters | A complete read or one precise unresolved step; no gate search |
| REVIEW-PROJECTOR-COST | [Difference algebra](../archive/work/theory_restart/jt2_difference_algebra.md) | Verify mixed-corner criterion and component count, retaining actual-tangle and common-normalization hypotheses | Proof, counterexample, or minimal missing hypothesis |
| REVIEW-ROOT-GATES | [Root gates](../archive/work/theory_restart/jt2_root_gates.md) | Check each root evaluation against Lickorish–Millett and the common-prefactor quantifiers | One reviewed proposition at a time |
| REPRODUCE-CERTIFICATE | [Reproduction guide](REPRODUCING.md) | Make one currently nonportable exact certificate run in a clean documented environment; compare saved output | One certificate, not an entire historical scan |
| REVIEW-SIKORA-DRAFT | [Manuscript](../archive/work/paper/sikora-uniqueness/main.tex) and [corrections guide](HUMAN_WORK_AND_CORRECTIONS.md) | Adversarial source and proof review, especially peripheral marking/orientation and the unframed extension | Report gaps or a complete scoped read; no automatic promotion |
| AUDIT-FAILURE-CARD | [Failure guide](FAILURES.md) | Independently reproduce one countermodel or withdrawn inference and check affected dependencies | One failure card with replayable evidence |
| EXACT-GADGET-REALIZATION | [JT₂ notes](../archive/work/theory_restart/jt2_difference_algebra.md) | One marked actual open tensor, composition law, size bound, common framing, and two-component output check | Stop at the first unproved realization step; no unsupported hardness claim |
| REFERENCES-AND-PRECEDENCE | [References](REFERENCES.md), claim index | Repair one missing source/version or a superseded status, with exact evidence | A small reviewable correction |

A contribution should include a short report even when it fails. Exact zero-testing hardness remains open in this program. The restrictions above eliminate particular architectures; they do not establish that all exact gadgets are impossible.
