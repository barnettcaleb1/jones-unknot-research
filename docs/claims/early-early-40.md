EARLY-40 — Strong-inversion reduction and obstruction to composite U anchoring
Status: INTERNAL-PROOF from standard knot topology.
K#reverse K is strongly invertible by swapping. Start with ribbon
R=K#reverse(mirror K), then R#reverse R: detection for strongly invertible
ribbon knots would imply generic detection. This does not make the SAME
composite knot a branch filling beside U.
No nontrivial composite determinant-one knot can share a rational-tangle
replacement system with an actual U filling: its branched cover is a
reducible integral homology sphere, contradicting the Gordon–Luecke
irreducibility consequence for surgery on an S3 knot. Such an anchored
Jones-one candidate would have to be PRIME.
Canonical ribbon-double disk group G_K is preserved by even band twists
and band-crossing switches (Hitt–Silver); actual-U ribbon boundary forces
disk group Z. These operations cannot create an actual-U anchor starting
from nontrivial K's canonical double. Composite fusion-one theorem also
forces fusion>=2 for double of hypothetical Jones-one nontrivial K.
Sources: work/proof13/tangle/{strong_inversion_reduction,unknot_anchor_primality}.txt;
work/proof12/tangle/findings.txt.
