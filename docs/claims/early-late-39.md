## Statement and recorded scope

```text
LATE-39 [IP/LI] BRUNNIAN THETA-ARC LINEAR UNZIP FILTER
For a relative arc G with planar-theta comparison, unzipping a COMPLEMENTARY
edge is R-linear in [G]. Elementary skein therefore forces the unzip Jones
to match T(2,k). An actual unzip J with det(J)>span(V_J), det(J)>1 (or the
stronger det(J)>displayed crossing count) excludes that arc.
Jang et al.'s Gamma(n,m) has red unzip
 trefoil # denominator-closure(-3/(6(n+m)+5)).
Writing s=n+m, its determinant 3|6s+5| exceeds the diagram crossing bound
|2s+1|+6 whenever s!=-1. This excludes retained blue/green edges on those
parameters. Retaining red makes the tested unzip double G, so it is not
linear; the exceptional line s=-1 also escapes this test.
The source argument misses denominator -1 at s=-1. This is a gap in that
specific argument, NOT a disproof of the full paper's theorem. No exceptional
candidate was established. Drilling a Brunnian theta curve does not simply
provide two rational unknot closures; one condition becomes edge deletion.
File: research49/arc_geometry.txt.
```
