MID-08  D/C  Brunnian equivalence and adjacency amplification in the u=1 case
------------------------------------------------------------------------
Equivalent EXISTENCE assertions, with the stated marked symmetries:
(i) a nontrivial u=1 knot with V=1;
(ii) a nontrivial strongly invertible S^3 knot whose preferred, actually
     unknot-anchored quotient bracket is the rational-zero vector;
(iii) a nonsplit two-unknot lk=0 componentwise strongly inverted pattern
      with normalized shell factor d=0.
The new (ii)=>(iii) uses an actual strongly inverted Brunnian triple from
an adjacent-to-U source and infection by the flat core. Pairwise splitness
keeps component unknots; source surgeries certify nonsplitness. It does not
reduce arbitrary hypothetical Jones-one knots to u=1.
Conditional amplification: if (i), for EVERY n>=1 there is a nontrivial
Jones-one knot K_n with n marked crossings for which changing ANY nonempty
subset gives U. The knots may differ with n; g(K_n)>n/3 and for n>=3,
Delta_Kn=1. Genus/adjacency claims use the cited established results.
Normalized Brunnian operations obey
 F(Q0+xv,Q0+yv)=Q0+c_B(A)xyv,
and with more slots the product of all input defects. A flat input gives
zero; a nonzero c_B cannot manufacture the first flat input.

work/cancellation19/brunnian_reduction.txt, adjacency_amplification.txt,
