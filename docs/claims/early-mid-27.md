MID-27  D/N  Actual finite-order inverses, but no exact realization
------------------------------------------------------------------------
Using the actual equal-ordinary-Jones pair with color3 difference
320h^5+O(h^6), Habiro inverse representatives yield, for every N>=5, actual
knots R_N with V_RN(e^h)=1+O(h^(N+1)) but H3_RN(e^h)=1+320h^5+O(h^6).
V_RN is provably NONUNIT (contains a nonunit Jones factor) and has >=N+1 terms
by Vandermonde. Every realizable finite ordinary-Jones jet fiber therefore has
unbounded bridge and reduced rational Kh rank via connected sums.
The particular completed ratio Z(5_1)/Z(10_132) cannot be one finite knot's
exact invariant: its color3 ratio is not Laurent, numerator span34 versus
denominator span48 in u. This corrects earlier optimism about exact realization.
A separate formal cyclotomic example a2=q-1 has all-color Laurentness but no
claimed group-like Jacobi lift or finite-order actual realization. Do not merge
the properties of these different formal constructions.
Files: work/research28/quantum_promotion.txt, quantum_promotion_audit.txt,
verify_promotion_jet.py; work/proof12/braid/all_color_collision_check.py.
